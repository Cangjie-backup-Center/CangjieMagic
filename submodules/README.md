本目录为 **Cangjie Magic** 的子仓目录，开发者可通过下方命令进行克隆。

如若还未下载 Cangjie Magic 代码仓，可选择克隆主仓的同时递归克隆‌子仓：
```
git clone --recursive https://gitcode.com/Cangjie-TPC/CangjieMagic.git
```

若已完成 Cangjie Magic 的下载，则可以选择后补克隆的方式下载：
```
cd CangjieMagic
git submodule init
git submodule update
```

更多关于开源应用的说明详见子仓 `README.md` 。
