## 说明

在运行这个示例程序之前，需要安装 MCP Server：

- [filesystem](https://github.com/modelcontextprotocol/servers/tree/main/src/filesystem)
- [markdownify-mcp](https://github.com/zcaceres/markdownify-mcp)

修改程序中的两个路径变量：

- `MARKDOWNIFY_DIR`：markdownify-mcp 项目的路径
- `MOUNT_DIR`：助手需要管理的文件夹路径

**⚠️ 注意**：在 Windows 上运行时，markdownify 工具可能会出错 [link](https://github.com/zcaceres/markdownify-mcp/issues/5)。
